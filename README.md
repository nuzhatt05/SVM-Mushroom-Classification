This repository is focused on implementing **Support Vector Machine (SVM)** for classification using the `mushroom.csv` dataset.

## Objective

## Dataset Description

The **Mushroom dataset** contains various attributes describing physical characteristics of mushrooms.  
Columns include:  

- **cap_shape, cap_surface, cap_color** – Mushroom cap properties  
- **bruises, odor** – Physical conditions and smell  
- **gill_attachment, gill_spacing, gill_size, gill_color** – Gill characteristics  
- **stalk_shape, stalk_root, stalk_surface_above_ring, stalk_surface_below_ring, stalk_color_above_ring, stalk_color_below_ring** – Stalk properties  
- **veil_type, veil_color** – Veil attributes  
- **ring_number, ring_type** – Ring details  
- **spore_print_color** – Spore print color  
- **population, habitat** – Growth details  
- **stalk_height, cap_diameter** – Numerical size-related features  
- **class** – Target variable: edible or poisonous
